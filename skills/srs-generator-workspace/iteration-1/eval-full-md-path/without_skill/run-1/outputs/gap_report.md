## B. 模板要求但目前缺失 / 不足、需要补充的文档或信息

### B1. 关键缺失（强烈建议补齐后再定稿）

1. **通信矩阵（CAN / UART DBC）** —— 最关键缺口。
   - 系统需求变更履历明确依据《多功能制氧机通信矩阵 V1.0_20260427》制作，但该文件**未包含在本项目目录中**。
   - 影响：模板「软件外部接口及信号映射」「功能需求」需要每个报文/信号的 **ID、字节位置、起始位、长度、分辨率、Offset、物理范围、周期、初始值**。当前仅能从系统需求正文得到信号名称与档位含义（如 `OXY_Seat_ION_SCN_Ctrl`、`OXY_Seat1_Ctrl_Nasal_Gear` 等），缺少完整 DBC 级定义。SRS 中相关位定义均以 **【TBD: 需通信矩阵】** 标注。

2. **HSI 文档（正式版）/ 软硬件接口签署版**。
   - 已有 MCU 管脚定义与端口定义 Excel，可临时充当 HSI，但模板期望一份正式 HSI（含 MCU↔传感器/执行器接口、唤醒源、上下拉）。建议补一份正式 HSI 并由系统/硬件会签。

3. **技术安全概念（TSC）/ 功能安全相关文档**。
   - 模板「安全性 / Safety」「功能需求 ASIL 字段」要求 SRS 源自 TSC。系统需求中功能安全为「预留（ASIL-B 思路）」，无 TSC/HARA 输出。所有需求条目 **ASIL 字段暂填【TBD】**。

4. **诊断需求规格（UDS / DTC 列表）与 Bootloader 规格**。
   - 系统需求与模板均列出 UDS、Bootloader 功能，但系统需求文档**未展开** UDS 服务列表、DID、DTC、刷写流程；产品需求有章节标题但本 SRS 输入中无细节。需补：UDS 服务/会话/安全访问定义、DTC↔故障码映射、Bootloader（A/B 分区、CAN 刷写）规格。

5. **网络管理（NM）规格**。
   - 系统需求仅给出「无报文 5s（暂定）休眠、CANFD 唤醒」。缺 OSEK/AUTOSAR NM 报文、NM 超时、部分网络（PNC）等定义。

### B2. 信息不足 / 待澄清（影响需求可测试性）

6. **大量「暂定 / 预留」参数需冻结**，否则需求无法量化验证。系统需求中包括：
   - 故障检测阈值与持续时间（过流 35A/3s、过温 70℃/3s、检测周期 200ms 等均标「暂定」）；
   - 休眠超时 5s「暂定」；
   - 滤网更换提醒「累计运行月数 >12 个月暂定」；
   - 制氧转速/四通阀/反吹阀时序中「红色部分需后续标定」；
   - 4L/6L/8L 档、香氛三香型三档、负氧离子缺水/个数等多处标「预留」。

7. **氧浓度安全停机阈值与动作链路缺定义**。功能清单写「氧浓度≥23.5% 停机报警（预留）」，但功能正文未给出该判定→停机→报警的完整需求。需明确传感器来源（LIN 氧浓度传感器）、阈值、迟滞、动作。

8. **传感器换算与标定基准**。MCU 管脚表给出 ADC 换算公式（NTC、电流、电压、压力），但压力/流量/氧浓度的**工程量标定曲线**未提供；标定功能本身为「预留」。

9. **非易失存储（NVM）内容定义**。模板第 6 章要求列出 Data Flash 内容（信号名/ID/默认值/单位）。系统需求仅提到「掉电记忆」「故障状态写 EEPROM」，缺 NVM 数据字典（哪些参数、地址、默认值、掉电保存策略）。

10. **软件平台 / 架构基线**。系统需求提到「支持 AUTOSAR」「支持 OTA（A/B 分区）」，但未确定具体 SW 平台、RTOS、BSW 版本、变体管理策略；模板「软件产品概览」需填这些。

11. **实时约束与资源预算的分解**。系统需求给整机级指标（响应 ≤200ms、CPU≤80%、Flash/RAM≤80%）。需把响应时间分解到任务/调度层（采样周期、控制周期、报文周期），否则「实时约束」章节只能照搬系统级数字。

12. **变体定义**。模板要求列硬件/软件变体（如 12V/24V/48V、内置活塞/外置涡旋、PSA/VPSA）。系统需求提到兼容多电压与双气源，但未形成正式变体矩阵。

### B3. 流程性 / 评审信息

13. **项目标识信息**：项目 ID、客户、车型（NIO NT3 线索见附录测试标准）、产品类型等模板「产品定义」表字段，需项目经理确认填写。
14. **审核 / 批准人、需求成熟度、Test by、Release Plan** 等需求属性字段需在评审时回填。

---

## 结论
- 在**现有资料**下，已可生成覆盖系统需求全部功能/非功能项的 SRS 初稿（见 `srs_draft.md`），软件信号映射与 HSI 借助 MCU 管脚/端口 Excel 已较完整。
- **定稿前必须补齐**：① 通信矩阵 DBC、② TSC/功能安全、③ UDS+Bootloader 规格、④ NM 规格，并冻结 B2 中的「暂定/预留」参数。
- SRS 初稿中所有缺口位置均以 **【TBD: …】** 显式标注，便于后续逐项闭环。
